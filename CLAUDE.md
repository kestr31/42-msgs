# sim42_msgs -- Developer Context

## Git Conventions

- Do not include "Co-Authored-By", "Generated by", or any other AI/Claude attribution in commit messages.

## What This Is

A ROS2 Jazzy interface package containing custom `.msg` and `.srv` definitions for the NASA 42 spacecraft simulator bridge. These types model 42's text-based TXRX IPC protocol variables as structured ROS2 messages.

This package has **no runtime code** -- only IDL definitions compiled by `rosidl_default_generators`.

## ROS2 Environment

- **Distro:** Jazzy
- **Source ROS2:** `source /opt/ros/jazzy/setup.bash` (bash) or `source /opt/ros/jazzy/setup.zsh` (zsh)
- **Build system:** ament_cmake / rosidl

## Message Categories

### Telemetry (42 -> ROS2)

| Message | 42 Variable | Description |
|---------|-------------|-------------|
| SimTime | `TIME` line | Simulation clock |
| AttitudeState | `SC[i].qn/wn` | Quaternion + angular velocity |
| OrbitalState | `SC[i].PosR/VelR`, `Orb[i].PosN/VelN` | Relative + absolute position/velocity |
| EnvironmentState | `SC[i].svb/bvb/Hvb` | Sun, magnetic field, momentum vectors |
| WheelState | `SC[i].Whl[k].H` | Wheel angular momentum |
| BodyState | `SC[i].B[k].wn/qn` | Per-body state |
| JointState42 | `SC[i].G[k]` | Joint positions and rates |
| GyroArray | `SC[i].Gyro[k].TrueRate` | Gyro angular rates |
| MagArray | `SC[i].MAG[k].Field` | Magnetometer readings |
| AccelArray | `SC[i].Accel[k].TrueAcc` | Accelerometer readings |
| CssArray / CssData | `SC[i].CSS[k]` | Coarse sun sensor |
| FssArray / FssData | `SC[i].FSS[k]` | Fine sun sensor |
| StarTrackerArray / StarTrackerData | `SC[i].ST[k]` | Star tracker |
| GpsState | `SC[i].GPS[k]` | GPS receiver |

### Commands (ROS2 -> 42)

| Message | Description |
|---------|-------------|
| StateOverride | Selective state override with per-field validity flags |
| JointCommand | Single-joint position command |
| WheelCommand | Wheel torque (future -- requires AcIPC) |
| MtbCommand | MTB moment (future -- requires AcIPC) |
| ThrusterCommand | Thruster pulse width (future -- requires AcIPC) |

### Services

| Service | Description |
|---------|-------------|
| GetSimStatus | Query connection status, message counts, sim time |
| SetSimState | One-shot state override via service call |
| ResetConnection | Force socket reconnect |

## Conventions

- All messages with a timestamp use `builtin_interfaces/Time stamp`.
- Quaternions: `[x, y, z, scalar]` -- matches 42's convention and maps directly to ROS2's `geometry_msgs/Quaternion [x, y, z, w]`.
- Array sensor messages (CssArray, FssArray, StarTrackerArray) contain sub-messages (CssData, FssData, StarTrackerData) as elements.
- Variable-length arrays (wheels, gyros, etc.) use `float64[]`. Fixed-size vectors use `float64[N]`.
- Flattened multi-DOF arrays (JointState42, BodyState) document their layout as `[count x DOF]`.

## Build

```bash
source /opt/ros/jazzy/setup.bash
colcon build --packages-select sim42_msgs
source install/setup.bash
```

Build this package **before** sim42_bridge, which depends on it.

## Dependencies

- `std_msgs`
- `builtin_interfaces`
- `rosidl_default_generators` (build) / `rosidl_default_runtime` (exec)
